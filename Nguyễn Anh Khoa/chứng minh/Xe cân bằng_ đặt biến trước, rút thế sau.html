Xe cân bằng → không gian trạng thái

Thứ tự mới: đặt biến trước, rút thế sau.

Bước 0: Hai phương trình gốc

Đặt u = TL + TR (tổng mô-men hai bánh). Đổi tên hệ số cho gọn:

a1 = a = 2Iw/R² + 2m + Ma2 = Mlc3 = c = Iy + Ml²
b1 = 1/Rb2 = Mglb3 = −1

(1)   a1·ẍ + a2·θ̈ = b1·u

(2)   a2·ẍ + c3·θ̈ = b2·θ + b3·u

Hai ẩn là ẍ và θ̈, nằm lẫn trong cả hai phương trình.

Bước 1: Đặt biến trạng thái ngay

x₁ = x,   x₂ = ẋ,   x₃ = θ,   x₄ = θ̇

Vậy ẍ = ẋ₂ và θ̈ = ẋ₄.

Lý do: x và θ có đạo hàm bậc hai, nên mỗi biến cần 2 biến trạng thái (nó và đạo hàm của nó).

Bước 2: Thay vào, được 4 phương trình

(1)   a1·ẋ₂ + a2·ẋ₄ = b1·u

(2)   a2·ẋ₂ + c3·ẋ₄ = b2·x₃ + b3·u

(3)   ẋ₁ = x₂   (định nghĩa)

(4)   ẋ₃ = x₄   (định nghĩa)

(3), (4) đã xong. Chỉ còn (1), (2) là hệ 2 phương trình 2 ẩn ẋ₂, ẋ₄.

Bước 3: Rút thế tìm ẋ₂ và ẋ₄

Tìm ẋ₂. Từ (1) rút ẋ₄:

ẋ₄ = (b1·u − a1·ẋ₂) / a2

Thế vào (2):

a2·ẋ₂ + c3·(b1·u − a1·ẋ₂)/a2 = b2·x₃ + b3·u

Nhân hai vế với a2 cho hết mẫu:

a2²·ẋ₂ + c3·b1·u − a1·c3·ẋ₂ = a2·b2·x₃ + a2·b3·u

Dồn các số hạng ẋ₂ sang trái, còn lại sang phải:

(a1·c3 − a2²)·ẋ₂ = −a2·b2·x₃ + (c3·b1 − a2·b3)·u

Cục (a1·c3 − a2²) tự xuất hiện, chỉ là một con số. Chia hai vế cho nó là xong.

Tìm ẋ₄. Làm y hệt: từ (2) rút ẋ₂ = (b2·x₃ + b3·u − c3·ẋ₄)/a2, thế vào (1), nhân a2, dồn ẋ₄ sang trái:

(a1·c3 − a2²)·ẋ₄ = a1·b2·x₃ + (a1·b3 − a2·b1)·u

Cùng cục (a1·c3 − a2²) xuất hiện lần nữa. Vì nó lặp lại nên viết gọn là Δ = a1·c3 − a2². Chỉ là tên ngắn, không có gì thêm.

Chia cho Δ:

ẋ₂ = −a2·b2Δ·x₃ + c3·b1 − a2·b3Δ·u

ẋ₄ = a1·b2Δ·x₃ + a1·b3 − a2·b1Δ·u

Đây chính là phép "nghịch đảo ma trận 2×2" của tài liệu gốc, thực chất chỉ là rút thế.

Bước 4: Đọc ra A và B

Hệ số của x₃ nằm vào cột 3 của A, hệ số của u nằm vào B. Hàng 1, 3 chỉ có số 0 và 1.

A = 0100 00−a2·b2Δ0 0001 00a1·b2Δ0   B = 0 c3·b1 − a2·b3Δ 0 a1·b3 − a2·b1Δ

ẋ = A·x + B·u   với   x = [x₁, x₂, x₃, x₄]T

Ô A(4,3) = a1·b2/Δ > 0 nên robot tự đổ (có cực dương).

Bước 5: Thay lại ký hiệu gốc

A(2,3) = −(Ml)(Mgl)/ΔA(4,3) = a·Mgl/Δ
B(2) = (c/R + Ml)/ΔB(4) = −(Ml/R + a)/Δ

Khớp đúng với tài liệu gốc, với Δ = a·c − (Ml)².

Bước 6: Điều khiển

u = −K·x   →   hệ vòng kín:   ẋ = (A − B·K)·x

Chọn K để các cực của (A − BK) nằm bên trái (LQR làm việc này).

Chỉ giữ thăng bằng thì mỗi bánh nhận TL = TR = u/2.

Muốn robot rẽ: xem trang hệ quay (yaw).

Kiểm tra với l = 0.33 m

Cực hở: 0, 0, +10.73, −10.73 (một cực dương = tự đổ)

Cực hở nằm ở: s²·(s² − q) = 0 với q = a1·b2/Δ, nên s = ±√q.

Cực vòng kín (LQR): −43.0, −9.7, −0.70 ± 0.47j (ổn định ✓)

Muốn đổi l (khớp háng) → a1, a2, c3, Δ đổi → A, B đổi → K phải đổi theo.
